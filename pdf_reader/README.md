# Простая PDF Читалка (Simple PDF Reader)

Быстрая, легковесная и удобная настольная читалка PDF файлов на Python.

## 🚀 Как запустить

### Способ 1: Двойной клик (Самый простой)
* Дважды щелкните по файлу `run.bat` в папке `pdf_reader`.

### Способ 2: Перетаскивание файла (Drag & Drop)
* Перетащите любой файл `.pdf` прямо на файл `run.bat` — читалка откроется сразу с вашим документом.

### Способ 3: Через терминал
```bash
python reader.py
# или с открытием конкретного файла:
python reader.py "путь/к/документу.pdf"
```

## ✨ Основные функции

* **Быстрое открытие и рендеринг**: сверхбыстрый движок PyMuPDF с кристально четким отображением текста (High-DPI).
* **Удобная навигация**: переход на следующую/предыдущую страницу, быстрый переход к первой/последней странице или ввод конкретного номера страницы.
* **Масштабирование**:
  * Плавное приближение/отдаление колесиком мыши с зажатым `Ctrl`.
  * Кнопки `🔍 -` и `🔍 +`.
  * Автоподгонка по ширине окна (`Ctrl+W`) или по высоте страницы (`Ctrl+H`).
* **Полнотекстовый поиск (`Ctrl+F`)**: поиск по всему документу с автоматической подсветкой найденного текста на странице и переходом между совпадениями.
* **🌙 Ночной режим (`Ctrl+I`)**: инверсия цветов страниц (черный фон, светлый текст) для комфортного чтения в темноте.
* **🌓 Темы интерфейса**: переключение между темной и светлой темами оформления.
* **Поворот страниц (`Ctrl+R`)**: поворот на 90 градусов.
* **Запоминание прогресса**: при следующем запуске программа автоматически открывает последний читаемый файл и ту страницу, на которой вы остановились.

## ⌨️ Горячие клавиши

| Клавиша | Действие |
|---|---|
| `Ctrl + O` | Открыть PDF файл |
| `→` / `↓` / `PageDown` / `Пробел` | Следующая страница |
| `←` / `↑` / `PageUp` / `BackSpace` | Предыдущая страница |
| `Home` / `End` | Первая / Последняя страница |
| `Ctrl + Колесико мыши` | Плавное масштабирование |
| `Ctrl + +` / `Ctrl + =` | Увеличить масштаб |
| `Ctrl + -` | Уменьшить масштаб |
| `Ctrl + 0` | Сброс масштаба на 100% |
| `Ctrl + W` | Подогнать по ширине окна |
| `Ctrl + H` | Подогнать по высоте страницы |
| `Ctrl + I` | Включить / выключить ночной режим страниц |
| `Ctrl + R` | Повернуть на 90° |
| `Ctrl + F` | Открыть поиск по тексту |
| `Escape` | Закрыть панель поиска |
| `F11` | Режим во весь экран |
